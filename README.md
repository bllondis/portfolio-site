# Tetiana Dovgalenko – Portfolio

My personal portfolio as a Product Designer & AI Design Engineer.

**[View the site](https://bllondis.github.io/portfolio-site/)**

---

## Case studies

- **[Timeflow](https://bllondis.github.io/portfolio-site/cases/timeflow.html)** – AI timesheet assistant, solo from research to a deployed full-stack app
- **[BookIT](https://bllondis.github.io/portfolio-site/cases/bookit.html)** – new admin modules for an enterprise ERP platform: spaces management, floorplan editor, events
- **[DocuStream](https://bllondis.github.io/portfolio-site/cases/docustream.html)** – B2B SaaS for UCC filing management

## About the site

- **Interactive cosmos** – case studies are reached through orbital planet animations instead of a standard grid
- **Own visual system** – Urbanist as the only typeface and a fixed palette (pale sky, paper, ink)
- Custom cursor and canvas animations

## Tech

- **Vite + React**
- **GitHub Actions** – every push to `main` builds the site and deploys it to GitHub Pages
- Case studies are standalone HTML pages in `public/cases/`

Built with AI coding tools (Claude Code, Antigravity, Cursor): I design, direct and review, the tools write much of the code.

## Run locally

```bash
npm install
npm run dev
```
